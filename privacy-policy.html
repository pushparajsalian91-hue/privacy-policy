Privacy Policy

PDF Splitter Pro Chrome Extension · Last updated: May 2025

📋 Summary: PDF Splitter Pro processes your PDF files entirely on your own device. No PDF content is ever uploaded to any server. The only external call we make is to Gumroad's API to verify your license key if you purchase Pro.

1. What We Collect

PDF Splitter Pro collects no personal data and does not track usage or analytics.

  • PDF files: Processed locally in your browser. Never uploaded or transmitted anywhere.
  • License key: If you purchase Pro, your Gumroad license key is stored locally in chrome.storage.local on your device only, and sent to Gumroad's API (api.gumroad.com) solely to verify its validity.
  • Split mode preference: Your last-used split mode is saved locally via chrome.storage.local.

2. How We Use Data

  • PDF content is read in-memory to perform splitting and, for Pro users, to extract field values for auto-naming. It is never stored beyond the current session.
  • The license key is sent to Gumroad only to verify that it is valid and has not been revoked. No other information accompanies this request.
  • We do not use cookies, analytics scripts, or any third-party tracking.

3. Data Sharing

We do not sell, trade, or share any user data with third parties, with the sole exception of the license key verification request sent to Gumroad (see Section 2). Gumroad's own privacy policy governs that interaction: gumroad.com/privacy.

4. Data Storage

All data stored by the extension (license key, split mode preference) is stored locally on your device using Chrome's chrome.storage.local API. This data does not leave your device except as described in Section 2.

5. Data Deletion

You can clear all extension data at any time by:

  • Going to chrome://extensions → PDF Splitter Pro → clicking Remove, or
  • Opening DevTools on the extension popup → Application → Storage → Clear site data.

6. Children's Privacy

This extension is not directed at children under 13. We do not knowingly collect any information from children.

7. Changes to This Policy

If we make material changes to this privacy policy, we will update the "Last updated" date above. Continued use of the extension after changes constitutes acceptance of the updated policy.
